# agent-lab Protocols

P-1 Research: objective -> sources -> opposing evidence -> report.
P-2 Experiment: hypothesis -> bounded run -> observation -> evidence -> disposition.
P-3 Opposition: claim -> independent challenge -> counterexample/evidence -> reconciliation.
P-4 Ledger: append-only record with source SHA and evidence references.
P-5 Escalation: retry/replan first; escalate only on policy, security, canonical-boundary, or recovery exhaustion.
P-6 Failure: classify, preserve artifact, record provenance, select bounded recovery.

Experiment is not Mission. Experiment failure is evidence about a hypothesis, not automatic mission failure.
