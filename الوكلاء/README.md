# الوكلاء — سجل الوكلاء الرسمي

هذا المجلد هو نقطة الوصول الرسمية لحزم وكلاء المستودع.

## الوكيل الرسمي الحالي

### المستكشف AI

- الحزمة: `الوكلاء/المستكشف AI/`
- العقد الرسمي: `الوكلاء/المستكشف AI/المستكشف.md`
- التقارير الرسمية: `الوكلاء/المستكشف AI/تقارير المستكشف/`
- تسجيل GitHub: `.github/agents/المستكشف-ai.md`

## فصل وكلاء Red Team

سيكون لكل وكيل Red Team حزمة رسمية مستقلة ومسار تقارير مستقل. لا تُدمج تقارير Red Team مع `تقارير المستكشف`، ولا تُعامل معرفة المستكشف كدليل Red Team أو شهادة.

## قاعدة الوصول

ابدأ من هذا الفهرس للوصول إلى تعريف الوكيل، عقده، أدلته، وتقاريره الرسمية.

## معيار الامتياز

الوكلاء الرسميون الثمانية يخضعون لبوابة امتياز مشتركة مع امتحان تخصصي وحالات مضادة مستقلة لكل دور.

- `scripts/agent-learning/evaluate-agent-readiness.mjs` يقيس الجاهزية.
- `scripts/agent-learning/run-role-drills.mjs` ينفذ امتحانات الأدوار.
- `tests/security/ci/agent-readiness-evaluator.test.mjs` يمنع أي نتيجة أقل من 100 في العقد القابل للاختبار.

## المستكشفون المتخصصون

البنية الرسمية للمستكشفين الثلاثة مركزية تحت `الوكلاء/المستكشفين/`:

- `الوكلاء/المستكشفين/Architecture Scout/`
- `الوكلاء/المستكشفين/Technology Scout/`
- `الوكلاء/المستكشفين/Ecosystem Scout/`

كل حزمة تحتوي على الهوية والعقد والمهمة.  
تسجيل الاستدعاء الفعلي يبقى في `.github/agents/`، ومدخلات التشغيل machine-readable تبقى في `.agent-intelligence/scouts/`.
