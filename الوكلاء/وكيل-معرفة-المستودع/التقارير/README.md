# تقارير وكيل معرفة المستودع

هذا هو المسار الرسمي الوحيد لتقارير **FLIXO Repository Knowledge Agent**.

## تسمية التقارير

`<EXACT-SHA>.md`

كل تقرير مرتبط بـ SHA واحد محدد. لا تُستخدم تقارير SHA قديم كدليل على حالة SHA أحدث.

## محتوى التقرير

يجب أن يتضمن التقرير، كحد أدنى:

- هوية SHA والفرع.
- تغطية القراءة.
- لقطة قراءة `main` وSHA الخاص بها.
- خريطة المستودع والاعتمادات والرموز.
- إشارات الأمن والبيانات والتنفيذ.
- اكتشاف المهام والسلطات المتعارضة.
- المجهولات والقيود.
- جرد الملفات.

التقرير معرفة تشخيصية فقط، وليس شهادة GREEN أو دليل نشر.
