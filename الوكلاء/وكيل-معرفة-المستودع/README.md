# وكيل معرفة المستودع

هذه الحزمة هي المساحة الرسمية المجمّعة لوكيل **FLIXO Repository Knowledge Agent**.

## المحتويات

- `الوكيل.md`: العقد التنفيذي الكامل للوكيل، وهو النسخة الرسمية التي يجب أن تطابق ملف تسجيل GitHub.
- `العقد.md`: حدود السلطة، نموذج المعرفة، وحالات القدرة.
- `التقارير/`: تقارير المعرفة المرتبطة بـ Exact-SHA، تقرير واحد لكل SHA محلل.

## الدور

الوكيل مخصص للاستطلاع المعرفي فقط. يقرأ المستودع بعمق، يحدد البنية والعلاقات والاختلافات والمهام والحدود، ويصدر معرفة قابلة للمراجعة للوكلاء الآخرين.

## قراءة main

الوكيل مخول بقراءة `main` كمرجع منفصل للحقيقة الإنتاجية، مع تسجيل SHA الدقيق لكل من `execution` و`main` وعدم منح هذه القراءة أي سلطة كتابة أو دمج أو نشر.

## حدود التعديل

مخرجات الوكيل المعرفية الرسمية تذهب إلى `التقارير/`. الوكيل لا يعدّل `main` ولا يعلن شهادة أو GREEN ولا يغيّر `المهام.md`.

## مسار التسجيل

يبقى `.github/agents/flixo-repository-knowledge-agent.md` كملف تسجيل GitHub، ويجب أن يظل مطابقًا حرفيًا لـ `الوكيل.md`.
