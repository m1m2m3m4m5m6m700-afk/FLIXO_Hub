# المستكشف AI

**المستكشف AI** هو الوكيل الرسمي لاستكشاف المستودع وبناء معرفة دقيقة قابلة للمراجعة.

## الحزمة الرسمية

- `المستكشف.md`: العقد التنفيذي الكامل.
- `العقد.md`: حدود السلطة وحالات القدرة.
- `تقارير المستكشف/`: التقارير المرتبطة بـ Exact-SHA.
- `.github/agents/المستكشف-ai.md`: تسجيل GitHub الرسمي.

## الاختصاص

يقرأ `execution` بعمق، ويقرأ `main` كمرجع إنتاجي منفصل للمقارنة، ويسجل SHA الدقيق لكل مرجع.

الوكيل لا يكتب في `main`، ولا يغيّر `المهام.md`، ولا يدمج، ولا ينشر، ولا يصدر شهادة.

## فصل Red Team

المستكشف AI ليس وكيل Red Team. وكلاء Red Team لهم حزم وتقارير منفصلة حتى تكون نتائج الاستكشاف ونتائج الهجوم/الفحص الأمني قابلة للتمييز دون التباس.
