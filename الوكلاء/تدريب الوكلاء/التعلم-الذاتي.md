# FLIXO — التعلم الذاتي المؤتمت للوكلاء

هذه الطبقة تحول الخبرة التشغيلية إلى دروس قابلة لإعادة الاستخدام مع حفظ الدليل والمرجع الدقيق.

الحلقة الأساسية:
`EXPERIENCE -> RCA -> CANDIDATE -> INDEPENDENT REVIEW -> REPEAT -> REGRESSION -> PROMOTE`

قاعدة الثقة:
- دليل التشغيل مرتبط بالـExact-SHA.
- تغير SHA يجعل الدليل القديم بحاجة إلى إعادة تحقق.
- لا يصبح الدرس موثوقًا من نجاح واحد.
- لا يمنح التعلم أي صلاحية تنفيذية أو حوكمية جديدة.

التنفيذ الحالي يضم بالفعل تمارين دورية ومُقيّمًا مستقلًا وتقارير SHA-bound. الخطوة التالية للتعلم طويل الأجل هي ربط النتائج بذاكرة خبرة دائمة ومكتبة مهارات بعد اجتياز بوابة التفنيد والترقية.

نتائج التدريب تُحفظ كـGitHub Actions artifact مرتبط بالـSHA لمدة محددة، ولا تمنح workflow سلطة كتابة إلى المستودع.
