# سجل خبرة الوكلاء

هذه المساحة تحفظ عقد بيانات الخبرة والدروس، وليس شهادة الإنتاج.

كل تجربة يجب أن تحمل exact `testedSha` ومصدر الدليل ونتيجة المراجعة المستقلة.

الحالات:
- `CANDIDATE`: ملاحظة أو درس غير مكتمل الإثبات.
- `PROMOTED`: اجتاز شروط الترقية.
- `STALE_EVIDENCE`: الدليل مرتبط بـSHA لم يعد هو الحالي.
- `REVOKED`: تم سحب الدرس بعد ظهور دليل مضاد.

قاعدة أساسية: تغيير الشيفرة أو الصلاحيات لا يصبح أثرًا تعليميًا موثوقًا؛ التعلم المعرفي والإجرائي منفصل عن سلطة التنفيذ والحوكمة.
