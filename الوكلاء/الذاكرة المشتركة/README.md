# الذاكرة المشتركة للوكلاء

هذا المجلد هو **العقد المعماري المحلي** للذكاء الجماعي، وليس مخزن الحالة الحية.

المصدر الحي للذاكرة المشتركة:
- `public.flixo_agent_learning_events`
- `public.flixo_agent_shared_memory`
- `public.flixo_agent_shared_memory_reviews`
- `public.flixo_agent_shared_memory_usage`

القواعد:
- الوكيل يقرأ من الذاكرة قبل الاستكشاف عندما تكون ذات صلة.
- الوكيل يقترح التعلم بعد وجود دليل.
- لا يروج الوكيل معرفته بنفسه.
- المعرفة الحالية فقط بعد Exact-SHA والتحقق.
- المعرفة القديمة تُستخدم كفرضية لإعادة الاختبار، وليست كحقيقة.
- كل اقتراح/نتيجة بشرية قابلة للتتبع تبقى في `الوكلاء/التقارير/<وكيل>/`.
- `.agent-intelligence/inbox/` ممنوع للتقارير والاقتراحات والنتائج.
