# تقارير وكلاء FLIXO

هذا هو **مركز التقارير والاقتراحات والنتائج الرسمي والوحيد** لجميع وكلاء FLIXO.

## قاعدة حاكمة

**ممنوع على أي وكيل استخدام `.agent-intelligence/inbox/` لتخزين أو نشر:**
- التقارير
- الاقتراحات
- التوصيات
- نتائج الاستكشاف
- نتائج الاختبارات
- التحليلات
- مخرجات التطوير
- التسليمات

كلها تذهب فقط إلى مجلد الوكيل داخل هذا المركز.

### المسار

`الوكلاء/التقارير/<AGENT-ID> — <اسم الوكيل>/`

### التعلم المشترك

التقرير هو نقطة الإثبات البشرية لكل Learning Proposal. بعد اكتمال التقرير يمكن للوكيل إرسال الدرس/التحذير/النمط إلى طبقة الذاكرة المشتركة. لا تنتشر المعرفة غير الموثقة تلقائيًا؛ الترقية تتطلب تفنيدًا مستقلًا، استخدامًا مفيدًا متكررًا، ودليل regression على Exact-SHA.

### الضبط

- الهوية والمسار canonical من `الوكلاء.md`.
- `write_scope == report_scope == canonical report directory`.
- كل تقرير يحمل Exact-SHA.
- أي كتابة تقرير خارج المجلد المحدد = `REPORT-ROUTING-VIOLATION`.
- `.agent-intelligence/inbox/` ليس مسارًا بديلًا ولا مخزنًا مؤقتًا للتقارير.
- سجل النشاط التشغيلي يبقى في ملف الوكيل المخصص له، ولا يتحول إلى تقرير.
