# FLIXO Truth — MVP Truth Contract

Projection/validation only. This layer does not create a second registry, executor, verifier, task ledger, or production authority.

For each executable MVP capability the Truth record binds registry membership, executable state, ready state, execution mode, network policy, executor, parameter schema, safety limits, recovery policy, output contract, verifier identity, manual route, Agent Guided intent, acceptance criteria, and exact-SHA identity.

The expected ten-capability set is read from src/config/manual-capability-definition.ts by the verifier.
