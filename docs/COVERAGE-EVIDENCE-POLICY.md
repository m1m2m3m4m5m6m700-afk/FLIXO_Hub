# FLIXO Coverage Evidence Policy

## Canonical evidence

Coverage certification is based on exact-SHA internal coverage generated by `npm run test:coverage` on the same candidate SHA under verification.

The required artifact contains:
- `coverage/lcov.info`
- `coverage/exact-sha.txt`
- `coverage/lcov.sha256`

The evidence must be non-empty, structurally valid LCOV, bound to the checked-out commit SHA, and uploaded as an immutable GitHub Actions artifact.

The retired `apps/agent-editor` path is not a current coverage authority because that runtime was removed during recovery. Current coverage targets the canonical FLIXO Hub runtime and browser-critical paths.

## External Codecov

Codecov is not a certification authority. A missing or failed Codecov upload is not treated as PASS. The internal exact-SHA artifact is the repository's current coverage authority for this release line.

## Fail closed

Missing, malformed, stale, or SHA-mismatched coverage evidence is a failure. A coverage job that is skipped, cancelled, pending, or absent is not evidence of success.
