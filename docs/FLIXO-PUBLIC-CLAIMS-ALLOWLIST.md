# FLIXO Public Claims Allowlist

Public launch messaging may claim only the ten canonical executable MVP capabilities:

- background-remover
- image-upscaler
- image-cropper
- image-compressor
- image-converter
- image-effects
- video-trimmer
- video-cropper
- video-resizer
- video-compressor

Descriptions must remain factual:
- Background Remover: remove connected, uniform backgrounds locally.
- Image Upscaler: increase image dimensions with bounded browser processing.
- Image Cropper: crop and resize images for exact dimensions.
- Image Compressor: reduce supported image file size in the browser.
- Image Converter: convert supported raster image formats locally.
- Image Effects: apply bounded brightness, contrast, saturation, and grayscale adjustments.
- Video Trimmer: trim supported video locally in the browser.
- Video Cropper: crop supported video locally to a deterministic rectangle.
- Video Resizer: resize supported video locally to exact output dimensions.
- Video Compressor: compress supported video locally with bounded browser recording bitrate.

Other registry entries may be recognized, planned, unavailable, or non-MVP. Their presence in the registry is not launch authorization.

Do not advertise OCR, Pix Studio, object removal, watermark removal, image generation, or other non-MVP capabilities as part of the certified launch unless a later exact-SHA scope decision explicitly promotes them.
