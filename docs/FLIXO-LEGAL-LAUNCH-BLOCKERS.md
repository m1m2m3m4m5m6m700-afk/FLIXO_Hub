# FLIXO Legal / External Launch Blockers

Status: OPEN — repository documentation corrected where supported by repository evidence; external/legal approvals remain unverified.

## Repository code license

The current repository declares `AGPL-3.0-only` in `package.json`, and `LICENSE` contains the GNU Affero General Public License version 3 text. The README license badge must match this declaration.

**Still requiring legal/owner review:** the proposed additional attribution condition (including a “Powered by FLIXO Hub” notice and repository link) must not be represented as legally approved merely because AGPL-3.0-only is present. Obtain qualified legal review and explicit owner approval for the exact license/notice text and distribution model before launch. Do not describe AGPL alone as approving an additional restriction or condition.

## Public support contact

A real support contact must be configured and tested before launch. Never publish a fabricated email address or identity. Evidence required: the live public contact endpoint/address and a successful reachability test.

## Private security reporting

GitHub private vulnerability reporting or the approved security-advisory intake path must be enabled and tested before public launch. Evidence required: repository setting state and a safe test of the reporting path without submitting a real vulnerability.

## Search Console / analytics

External ownership verification, Search Console registration, sitemap submission, analytics provider configuration, and any required legal consent controls must be completed in the relevant external accounts. Evidence must identify the verified property and deployed origin; repository configuration alone is insufficient.

## Distribution accounts

Product Hunt, Hacker News, Reddit, X, LinkedIn, YouTube, and email delivery require account-level actions. Repository automation may prepare content and runbooks but cannot mark these actions complete without evidence from the relevant account or a documented decision that a channel is out of scope.

## Release rule

Each item remains OPEN until its stated evidence is recorded against the actual release origin and release SHA where applicable. Missing owner, legal, credential, or external-account authority is a release blocker, not a green state.
