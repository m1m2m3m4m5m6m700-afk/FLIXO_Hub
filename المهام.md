## 1. AUTHORITY MODEL

`execution` = canonical implementation/integration lane.

## 3. TASK CARD CONTRACT

كل بطاقة نشطة تحتوي **13 حقلًا وبنفس الترتيب الصارم**:

1. `TASK_ID`
2. `TYPE`: IMPLEMENT | VERIFY | INTEGRATE | GOVERNANCE | RELEASE | AUDIT
3. `PRIORITY`: P0 | P1 | P2 | P3
4. `OWNER`
5. `STATUS`: QUEUED | IN_PROGRESS | BLOCKED | OWNER_ACTION | VERIFYING
6. `PR`: `none` | `n/a` | `#N` | URL
7. `SCOPE`
8. `DEPENDS_ON`: comma-separated EXEC IDs or `none`
9. `SOURCE`
10. `EVIDENCE`: proof links/files or `none`
11. `ACCEPTANCE`
12. `NEXT_ACTION`: exactly one executable next step
13. `COLLISION_KEY`

عنوان المهمة بعد `###` ليس حقلًا. أي metadata إضافية داخل البطاقة ممنوعة.

لا تُعتبر المهمة منتهية بسبب ACK، single green test، source inspection، historical SHA، أو PR description.

## 4. AGENT LIFECYCLE

**DISCOVER → CLAIM → BASELINE → EXECUTE/VERIFY → ACCEPTANCE → REMOVE → COMMIT → RECOUNT**

- CLAIM فقط عندما يكون سطح التعارض حرًا.
- BASELINE يحل live `execution` SHA.
- Evidence مربوط بالـexact resulting SHA.
- REMOVE لا يحدث إلا بعد اكتمال Acceptance.
- COMMIT يجب أن يتضمن Task ID.
- أي SHA drift يلزم requalification.

## 4b. EXECUTION ENVELOPE CONTRACT

المهمة لا تكتسب صلاحيات تنفيذية من وصفها. عند **CLAIM** يُشتق Execution Envelope من بطاقة المهمة + عقد الوكيل + سياسة المستودع، ولا يُنشأ دفتر dispatch ثانٍ.

الحقول المعيارية:
```text
TASK-ID
AGENT-ID
MISSION
STARTING-SHA
ALLOWED-CAPABILITIES
READ-SCOPE
WRITE-SCOPE
FORBIDDEN-ACTIONS
EXPECTED-EVIDENCE
ACCEPTANCE-CONDITIONS
HANDOFF-CONTRACT
FINAL-SHA
```

- `AGENT-ID` يأتي من الهوية canonical في `الوكلاء.md` عند claim.
- `STARTING-SHA` يثبت عند claim ولا يُستنتج من SHA تاريخي.
- `ALLOWED-CAPABILITIES` = تقاطع Capability Contract للوكيل مع نطاق المهمة.
- `READ-SCOPE` و`WRITE-SCOPE` لا يتجاوزان حدود عقد الوكيل.
- `FORBIDDEN-ACTIONS` تُورث من Global Policy + Agent Contract.
- `FINAL-SHA` لا يُملأ إلا بعد التنفيذ وإنتاج evidence جديد.
- أي SHA drift يجعل evidence السابق stale.

الأولوية:
```text
Global Policy > Agent Contract > Task Envelope > Agent Local Decision
```

الـEnvelope projection مشتق من هذا الملف وليس مصدر dispatch بديلًا. غياب الهوية أو العقد الصالح = `PENDING_CLAIM/BLOCKED`.
