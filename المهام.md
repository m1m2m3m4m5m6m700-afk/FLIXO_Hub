## الحالة الحالية

- المسار التشغيلي الوحيد: `execution → main`.
- `main` هو مرجع الإنتاج، ولا تتم الكتابة المباشرة عليه.
- المرشح الحالي هو PR #1002؛ يجب دائمًا حل رأس `execution` الحي قبل اعتماد أي SHA.
- الـMVP التنفيذي المقفل هو عشر قدرات Browser-Local: ست صور وأربعة فيديو.
- Runtime authority الحالي محصور في `src/config/registry.ts` و`src/lib/execution/canonical-executor.ts` وعقود المخرجات وverifiers.
- بوابة الاختبار الحالية هي `npm test` مع اختبارات MVP المتخصصة للـregistry وscope وcorpus وexecutor وpersistence وRed Team.
- لا توجد حزمة Runtime حالية في `apps/agent-editor` أو `src/lib/agent/` السابقة؛ مسارات الاسترداد التاريخية موثقة منفصلًا.
- الحالة النهائية الحالية: `NOT READY` حتى إغلاق بوابة الحوكمة وإتمام Prompt 19/20.

- ممنوع انتظار handoff.

- ممنوع إعادة توزيع المهمة لمجرد أنها صعبة.
- أي عيب تقني واضح ضمن صلاحيات الإصلاح يعالج مباشرة.
- أي ملف له مالك أساسي واحد.

- كل وكيل يعمل على branch مستقل ويعرض PR إلى execution.
- يعتمد كل وكيل على العقود والـrepository state، لا على رسائل الوكلاء.
- أي تغير في execution لا يوقف العمل؛ عند الدمج يعاد التحقق فقط من الاختبارات المتأثرة وتُجدد الأدلة للـSHA الناتج.

## Governance blocker

Ruleset `FLIXO-MAIN-PROTECTION` (ID 23854302) is active for `main`, but the live policy is weaker than the active plan requires:

- approving reviews = 0 (required 1)
- stale reviews dismissed on push = false (required true)
- Code Owner review = false (required true)
- latest push approval = false (required true)
- review-thread resolution = false (required true)
- strict required checks = false (required true)

PR #1002 also has no independent human approving review. Automated security comments are not equivalent to a human approval.

## Evidence rule

Any mutation on `execution` changes the candidate SHA and invalidates prior SHA-specific certification evidence. No stale or skipped evidence may be used to certify the release.

Historical recovery and certification records remain available under `docs/` but are not current runtime authority.
